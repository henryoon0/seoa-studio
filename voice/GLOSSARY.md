## 모듈 구성

| 용어 | 뜻 |
|---|---|
| 말투 모듈 | 이 폴더(`workspace/seoa-voice`) 전체. 어디든 붙이는 단위. |
| 말투 규격 | `VOICE.md`. 프롬프트 맨 앞에 붙이는 규칙 문서. |
| 채널 | 글이 나가는 곳. 인스타 캡션·쇼핑몰 노트·카드뉴스·댓글 답글·카톡 메시지 5개. |
| 다이얼 | 채널마다 다르게 조절하는 값(이모지·ㅋㅋ·길이·인스타 말). `VOICE.md` 3절 표. |
| 말투 DB | `db/` 폴더. 아래 4개 파일. |
| 원문 글 | `db/posts.jsonl`. 서아님 인스타 글 원문(캡션·영상 대본·반응 수). 말투의 1순위 근거. |
| 답글 | `db/replies.jsonl`. 서아님이 단 댓글과 그 앞의 단비님 질문. 댓글·카톡 말투의 근거. |
| 자동 답글 | 답글 중 `auto: true`. 10번 넘게 같은 문장을 붙인 공구 안내. 말투 예시로 쓰지 않는다. |
| 노트 원고 | `db/manuscripts.jsonl`. 원문 글을 AI가 쇼핑몰 노트로 옮긴 결과. 2순위 근거(사람이 다 검토하지 않음). |
| 측정값 | `db/stats.json`. 문장 끝·줄 길이·이모지·자주 쓰는 말 빈도. |
| 반응 점수 | 좋아요 + 댓글 × 3. 예시를 고르는 기준. |
| 예시 뽑기 | `scripts/examples.py`. 주제어로 DB에서 예시를 뽑아 프롬프트에 붙인다. |
| DB 갱신 | `scripts/build_db.py`. 원본에서 DB를 다시 만든다. |
| `[확인 필요: 무엇]` | 원본에 없는 사실 자리에 남기는 표시. 지어내지 않는다는 약속. |

## 작업 순서 (다음에 이 일을 할 때)

1. 새 인스타 글이 쌓였으면 `simplyhome-article`에서 수집을 돌린다.
2. `python3 scripts/build_db.py`로 말투 DB를 다시 만든다.
3. 글을 쓸 때 `VOICE.md` + 채널 + 예시 뽑기 결과 3~8개를 프롬프트에 붙인다.
4. 결과를 `VOICE.md` 4절 점검표로 확인한다.
5. 서아님이 고친 글이나 카톡 원문이 생기면 `db/raw/`에 넣고 규격을 고친다.
